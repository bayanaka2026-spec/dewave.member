deWAVE Member Android App

Cara membuat APK dari HP:
1. Buat repository baru di GitHub, misalnya: dewave-member.
2. Upload SEMUA isi folder project ini ke repository tersebut.
3. Pastikan file .github/workflows/build-apk.yml ikut ter-upload.
4. Buka tab Actions -> Build deWAVE APK -> Run workflow.
5. Tunggu sampai selesai (centang hijau).
6. Buka hasil workflow -> bagian Artifacts -> download deWAVE-APK.
7. Extract ZIP, lalu install app-debug.apk di HP.

APK ini membuka Web App deWAVE Alam Sutera yang sudah disiapkan.
